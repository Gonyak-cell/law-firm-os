# G0 지정 책임자 승인 대기

기술 계약과 synthetic fixture 검증은 완료됐지만 다음 세 책임자 지정은 제품·법률 결정이므로 추정하지 않는다.

| 결정 | 현재 상태 | 필요한 기록 |
|---|---|---|
| 송무·기업 자문·분쟁·트랜잭션 분야 책임자 | 미지정 | 분야별 책임자 이름 또는 단일 공통 책임자 이름 |
| Worktree 권한 규칙 책임자 | 미지정 | 권한 매트릭스를 승인할 책임자 이름 |
| 법률업무 템플릿 승인자 | 미지정 | 템플릿 `draft → approved` 전환을 승인할 이름 |

지정 전 강제 상태:

- 실제 법률업무 템플릿은 `draft` 유지
- `template:approve` 권한 부여 없음
- synthetic `[QA]` 템플릿만 테스트에서 사용
- 구현 및 내부 패키지 QA와 공개 릴리스·AWS 배포 주장을 분리
