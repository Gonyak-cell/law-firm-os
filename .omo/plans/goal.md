# People 전체 메뉴 구현 목표

## 목표

`People 전체 메뉴 구현계획 v2`의 `PEO-TUW-001`부터 `PEO-TUW-070`까지를 실제 화면 → API → 도메인 → 저장소 → 외부 포트 기준으로 검증하고, 발견된 소스 미구현을 모두 보완한다.

## 기준 문서

- 원 계획: `.lazyweb/design-improve/people-tuw-detailed-plan-v2-2026-07-30/report.html`
- 재검증·보완 계획: `.omo/plans/people-goal-remediation-20260731.md`
- 구현 범위: `PEO-TUW-001..070`과 `PEO-FIX-*`
- 작업 브랜치: `codex/people-implementation-v2-20260730`
- 기준 커밋: `140f1ad10af310fe54637a9058c786b115917beb`

## 제품 원칙

- 10명 안팎의 소규모 로펌에 필요한 오늘 업무, 시간 단위 일정, 담당 사건, 업무 집중도, 승인·인계 신호를 우선한다.
- 인원 증감, 입·퇴사 추이와 같은 대기업형 인사 KPI는 대시보드에 추가하지 않는다.
- 자연스러운 한국 SaaS 용어를 사용하고 내부 ID·구현 용어·번역투를 화면에 노출하지 않는다.
- 재판은 해당 시점의 담당 변호사로 지정된 경우에만 오늘 할 일에 포함한다.
- Outlook 회의는 필수 참석자일 때만 오늘 할 일에 포함하고, 선택 참석 일정은 오늘 일정에만 표시한다.
- 기존에 비활성화된 사이드바 메뉴와 직접 경로는 활성화하지 않는다.

## 완료 조건

1. 모든 계획 단위와 보완 단위가 코드·테스트·증빙에 양방향으로 연결된다.
2. 기능 플래그, 권한, step-up, tenant 격리, 멱등성, 재시작 영속성, 개인정보 보호의 음성 경계가 통과한다.
3. 전체 package/API/Web 회귀, 타입 검사, production build, HRX 권한·보안·UI·release 검증이 통과한다.
4. 1440px·1024px·390px 실제 화면에서 핵심 정보, 작업 버튼, 시간표와 구성원 상세를 확인한다.
5. 현재 소스 해시로 구현 현황·급여 역량·화면 증빙 영수증을 다시 생성한다.
6. 독립 코드 리뷰와 최종 게이트 리뷰에 HIGH 차단 항목이 없다.

## 완료 경계

소스 구현 완료는 운영 준비 완료나 배포 완료를 뜻하지 않는다. 다음은 실제 권한·비밀값·외부 시스템·동일 SHA 배포가 있어야 닫을 수 있는 별도 게이트다.

- Microsoft 365 tenant consent와 운영 token vault/calendar adapter
- 채용 자료 출처, 후보자 동의 증거, Vault 문서와 보상 패키지의 운영 권위
- 실제 은행 지급 제공자
- 실제 세무·4대보험 신고 제공자
- 실제 급여명세서 전달 제공자
- 실제 법률 검토 승인 기록
- 동일 소스 SHA의 패키징·배포·로그인 상태 화면 검증

이 게이트가 닫히기 전에는 `production_ready` 또는 실제 외부 연동 완료를 주장하지 않는다.
