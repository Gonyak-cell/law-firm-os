# 현재 Matter 앱 UI 메뉴 및 버튼 인벤토리

작성일: 2026-07-10

범위:
- 최신 로컬 패키지 앱 기준: `apps/desktop/dist/mac/matter.app`.
- 패키지 식별값: `CFBundleIdentifier=com.amic.matter.desktop.internal`, `CFBundleShortVersionString=0.1.10`.
- 패키지 안의 실제 렌더러 경로: `apps/desktop/dist/mac/matter.app/Contents/Resources/app/src/renderer/web/index.html`.
- UI 라우트와 컨트롤 기준 파일: `apps/web/src/components/Shell.jsx`, `apps/web/src/data/nav.js`, `apps/web/src/data/globalUtilities.js`, `apps/web/src/people/peopleFeatureCatalog.js`, `apps/web/src/components` 및 `apps/web/src/people` 아래 활성 surface 컴포넌트.

주의:
- 일부 버튼은 조건부로만 보입니다. 드로어, 상세 패널, 선택된 레코드, 인증 단계, 권한/검토 상태가 열렸을 때만 나타납니다.
- 데이터 행마다 반복 생성되는 버튼은 레코드 수만큼 나열하지 않고, 동일한 동작을 하는 "버튼 유형" 단위로 정리했습니다.
- 비활성화된 버튼도 사용자가 볼 수 있는 UI 신호라면 목록에 포함했습니다.

## 전역 Shell

### 상단 축 메뉴

| 라벨 | 라우트 | 의도한 기능 |
|---|---|---|
| Home | `view=home` | 로펌 전체 업무 지휘 화면을 엽니다. 대시보드, 승인, To Do, 피드, 캘린더, 메시지, 전자계약, 회사 현황, 매출/비용 라우트가 여기에 모입니다. |
| Client | `view=clients` | Client/CRM 업무를 엽니다. Client 대시보드, 목록, 계정 정보, 담당자, Opportunity, 상담, 이해상충, 관계, 청구, 리포트, 데이터 가져오기, 설정을 다룹니다. |
| Matter | `view=matters` | 사건 운영 화면을 엽니다. 사건 대시보드, 목록, 문서, 신규 사건, 수임 진행, 종결, 보관, 업무 보드, 할 일, 일정, 대화, 팀, 정산, 리포트, 검색, 위험, 감사, 연동, 설정을 다룹니다. |
| People | `view=people` | HRX/구성원 업무를 엽니다. 구성원, 조직, 역할, 근로정보, 근태, 휴가, 승인, 리포트, 급여, 메시지, 전자계약, 회사 설정을 다룹니다. |
| Vault | `view=vault` | 문서 관리 화면을 엽니다. 문서함, 문서 상세, 메일 보관함, 업로드, 검색, 보안 경계를 다룹니다. |
| Portal | `view=portal` | 외부 공유/의뢰인 포털 화면을 엽니다. 공유 홈, 요청 응답, 공유 링크, 감사 상태를 다룹니다. |

### 상단바 컨트롤

| 버튼/컨트롤 | 의도한 기능 |
|---|---|
| 전역 검색 입력창 | 제품 축과 전역 유틸리티를 검색합니다. 검색어가 있으면 검색 팝오버에서 라우트 바로가기를 만듭니다. |
| Create | 현재 화면의 생성 핸들러를 호출합니다. Shell 기준으로는 활성 컨텍스트의 기본 생성 진입점입니다. |
| 종 아이콘 / 알림 | 알림 드로어를 열고 읽지 않은 알림 수를 표시합니다. |
| 메시지 아이콘 | 메시지 드로어를 열고 읽지 않은 메시지 수를 표시합니다. |
| 방패 아이콘 / 승인 대기 | 승인 드로어를 열고 대기 중인 승인 수를 표시합니다. |
| 새로고침 아이콘 | 현재 surface의 전역 새로고침을 실행합니다. |

### 유틸리티 드로어 버튼

| 버튼 | 드로어 | 의도한 기능 |
|---|---|---|
| 스크림 / X 닫기 | 모든 드로어 | 열린 드로어를 닫습니다. |
| 읽음 처리 | 메시지 카드 | 메시지 카드 하나를 읽음 처리합니다. |
| 모두 읽음 처리 | 알림 | 모든 알림 항목을 로컬 상태에서 읽음 처리합니다. |
| 알림 설정 | 알림 | 드로어 안의 로컬 알림 설정 상태를 토글합니다. |
| 모두 읽음 처리 | 메시지 | 보이는 메시지를 모두 읽음 처리합니다. |
| 전체 보기 | 메시지 | `home#home-messages`로 이동합니다. |
| 전체 보기 | 승인 대기 | `home#home-requests`로 이동합니다. |

### 사이드바 전역 컨트롤

| 버튼/컨트롤 | 의도한 기능 |
|---|---|
| 업무로 돌아가기 | 프로필, 설정, 데이터 가져오기 같은 예외 모드 화면에서 보이며 저장된 업무 라우트로 돌아갑니다. |
| 워크스페이스 카드 | 현재 축의 로컬 워크스페이스 패널을 열거나 닫습니다. |
| 사이드바 그룹 토글 | 현재 축의 하위 그룹을 펼치거나 다시 눌러 접습니다. 한 번에 한 그룹만 열리며 상태는 `axis:view` 단위로 보존됩니다. |
| 사이드바 항목 버튼 | 선택한 라우트 섹션으로 이동합니다. |
| 사이드바 유틸리티 버튼 | 연결된 유틸리티 라우트로 이동하거나, 라우트가 없으면 로컬 유틸리티 패널을 엽니다. |
| 좌하단 프로필 버튼 | 독립 프로필 화면인 `view=profile`을 엽니다. |

### 전역 검색 팝오버

| 버튼/컨트롤 | 의도한 기능 |
|---|---|
| 검색 지우기 | 검색어를 비웁니다. |
| 제품 결과 버튼 | Home, Client, Matter, People, Vault, Portal 중 하나로 이동합니다. |
| 전역 유틸리티 결과 버튼 | 메시지, 알림, 요청함, 보고서, 설정, 전자계약, 일정, 매출/비용, 데이터 가져오기, 문서 같은 전역 유틸리티 기본 섹션으로 이동합니다. |
