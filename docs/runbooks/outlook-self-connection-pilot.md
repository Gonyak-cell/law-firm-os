# AMIC OS Outlook 연결 안내 — 내부 파일럿

대상은 AMIC 구성원 10명입니다. 각자 본인의 회사 Microsoft 계정으로 연결하며, 비밀번호·인증번호·로그인 링크를 다른 사람에게 전달하지 않습니다. Outlook은 버전 2409 이상을 사용합니다.

## 1. People에서 내 일정 연결

1. AMIC OS 데스크톱 앱에서 **People**을 엽니다.
2. 본인 이름을 선택한 뒤 **Outlook 일정**에서 **연결**을 누릅니다.
3. 새로 열린 Microsoft 로그인 창에서 본인의 `@amic.kr` 계정을 선택합니다.
4. 권한 화면을 확인하고 계속합니다. People은 기본 일정 정보 읽기 권한(`Calendars.ReadBasic`)만 사용합니다.
5. AMIC OS로 돌아와 Outlook 일정이 **연결됨**으로 바뀌었는지 확인합니다.

연결 후 본인이 필수 참석자로 지정된 오늘 회의만 **오늘 할 일**에 들어갑니다. 그 밖의 일정은 시간표에서만 확인할 수 있습니다. 재판기일은 해당 Matter의 담당 변호사로 지정된 경우에만 오늘 할 일에 표시됩니다.

## 2. Outlook에서 Client·Matter 연결

1. Outlook에서 보관할 메일을 하나 엽니다.
2. **AMIC OS** 작업창을 열고 AMIC OS에 로그인합니다.
3. **Outlook 연결**을 누른 뒤 같은 회사 Microsoft 계정으로 로그인합니다.
4. 권한 화면을 확인하고 계속합니다. 메일 보관은 `Mail.Read`, Client 일정 기능은 `Calendars.ReadWrite`를 사용합니다.
5. 작업창이 **연결됨**으로 바뀌면 추천된 Matter를 확인한 뒤 메일을 보관합니다. 추천이 맞지 않으면 직접 다른 Matter를 선택합니다.

People과 Client·Matter는 같은 Entra 앱을 사용하지만, AMIC OS 내부에서는 요청 권한·OAuth 상태·연결 기록·토큰 보관을 기능별로 따로 관리합니다.

## 연결이 멈춘 것처럼 보일 때

- 예전에 열어 둔 로그인 탭이나 브라우저가 복원한 탭은 사용하지 말고, AMIC OS의 **연결**을 다시 눌러 새 창에서 시작합니다.
- Microsoft 화면이 오래 멈추면 창을 닫고 AMIC OS에서 다시 시작합니다. 같은 로그인 화면의 주소를 복사해 다른 기기에서 이어서 열지 않습니다.
- 로그인 뒤에도 상태가 바뀌지 않으면 작업창이나 구성원 상세 화면을 한 번 닫았다가 다시 엽니다.
- 반복해서 실패하면 오류 문구와 발생 시각만 관리자에게 전달합니다. 비밀번호·인증번호·로그인 URL은 보내지 않습니다.

## 연결 해제

- People: 본인 상세의 **Outlook 일정 → 연결 해제**
- Client·Matter: Outlook의 **AMIC OS → 연결 해제**

연결 해제 뒤 화면이 미연결 상태로 바뀌는지 확인합니다. 다시 사용할 때는 각 화면에서 본인이 직접 연결하면 됩니다.
